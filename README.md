- `assets/` : photos et visuels

## Tester en local
Ouvre `index.html` dans ton navigateur.

## Déployer avec GitHub Pages
1. Crée un dépôt GitHub public, par exemple `portfolio-sport`.
2. Envoie tout le contenu de ce dossier à la racine du dépôt.
3. GitHub → **Settings → Pages**.
4. **Build and deployment** :
   - Source : `Deploy from a branch`
   - Branch : `main`
   - Folder : `/ (root)`
5. **Save**.
6. L'URL sera du type :
   `https://TON-UTILISATEUR.github.io/portfolio-sport/`
